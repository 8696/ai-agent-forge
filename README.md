# 项目 A · AgentForge

> **AgentForge** = 多租户的 AI Agent 平台。第一个能力是文档问答，后续可叠加工具调用 / 多代理 / 工作流 / 多渠道等任何 Agent 能力。

## ⚠ 文档即系统规格（最重要）

> **这份文档不是写完就完的实施说明，而是整个系统的规格定义**。文档改了，代码必须跟；代码改了，文档必须跟。**文档和代码是 1:1 镜像关系，任何一边脱节都是 bug**。
>
> **改任何东西之前**，先看 [17-扩展指南.md §17.8 变更同步规则](./docs/17-扩展指南.md) —— 改 X 必须同步改 Y 的清单。

## 一句话目标

**做一个多租户的 AI 文档问答平台：后台管理员上传文档（PDF / Word / Markdown / TXT），系统拆块 + Embedding 入向量库；前台用户通过对话向 AI 查询文档里的知识。**

## 怎么读这份文档

推荐顺序：

1. **README.md**（你正在看）：了解项目目标 + 文件结构
2. **02-系统架构与目录.md**：先有大局观，知道每层做什么
3. **01-需求与场景.md**：知道要满足哪些业务需求
4. **03-a / 03-b / 03-c**（技术栈 3 份）：知道用什么技术、怎么写代码
5. **04-a / 04-b / 04-c / 04-d**（UI 需求 4 份）：知道每个页面长什么样
6. **05-a / 05-b**（数据模型 2 份）+ **06-API接口.md**：知道数据怎么存、接口怎么调
7. **07-大模型与Embedding.md**：知道用哪个模型、协议怎么走
8. **08-a ~ 08-f**（24 模块 6 份）：核心章节，每个模块怎么用、关键代码、选型理由
9. **09 / 10 / 11**：评测、观测、安全方案
10. **12-部署运维与成本.md**：本地怎么跑、备份怎么做、成本怎么算
11. **13-a ~ 13-e**（后端代码 5 份）+ **14-a ~ 14-d**（前端代码 4 份）：照着写代码时的具体参考（按需查）
12. **15-开发进度计划.md**：**开发的「施工图」**——14 个步骤，每个步骤有「涉及需求 + 交付物 + 验收」，按顺序打钩走完项目就交付
13. **16-a ~ 16-e**（需求对照表 5 份）：**「需求 → 技术」的完整地图**——每条需求列了对应 Step、技术、实现位置、关键代码、验收
14. **17-扩展指南.md**：**「怎么往文档里加新内容」**——加新需求 / 加新步骤 / 加新模块的模板、命名约定、变更同步规则
15. **AGENTS.md**：**「AI 工程师操作手册」**——接手这份文档后该怎么干活（核心规则 / 任务流程 / 禁止事项）

## 不做（Out of Scope）

- 不做支付集成（用第三方支付）
- 不做电话客服 / 视频客服（只做文字）
- 不做复杂 CRM（只接已有系统的工具）
- 不做原生移动 App（响应式 Web）
- 不部署到任何云（本地运行，通过 localhost 访问）
- 不做复杂角色权限矩阵（3 个角色够：admin / agent / customer）
- 不做 **工具调用**（B3）：需要另外起一个业务系统项目（订单 / 工单 / 退款），本项目通过 MCP 接入即可
- 不做 **多代理协作**（B6）：单代理 + RAG + 记忆 已能跑通客服场景
- 不做 **工作流 + 人工审批**（B5）：没有外部工具调用就不需要审批
- 不做 **邮件渠道**（E1 部分）：接 SMTP 服务，前台通过邮件提问

## 附录 B · 风险清单

| 风险         | 等级 | 缓解措施                                                    |
| ------------ | ---- | ----------------------------------------------------------- |
| LLM API 挂   | 高   | Vercel AI SDK 自动重试 + 主备切换（换 model 参数）          |
| 成本失控     | 高   | 每租户 token 配额 + 超阈值告警 + Prompt Caching + lru-cache |
| 提示词注入   | 高   | 规则匹配 + 大模型二次确认 + 命中转人工                      |
| 检索召回率低 | 中   | 混合检索（BM25 + 向量）+ bge-reranker 重排序                |
| 数据泄露     | 中   | 脱敏（身份证 / 银行卡 / 手机号）+ audit_logs 全留痕         |
