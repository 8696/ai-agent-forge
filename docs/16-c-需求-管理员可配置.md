## C · 管理员可配置

### C1 · 知识库管理

**需求**：admin 上传 PDF / Word / Markdown / TXT；自动拆块 + Embedding + 入向量库。

**对应 Step**：Step 4

**使用技术**：

- @koa/multer（文件上传）
- pdf-parse / mammoth（PDF / Word 解析）
- 拆块（`splitByChunk`，size=800 / overlap=150，按段落）
- Embedding API（独立 REST）
- Qdrant client（写入）
- MySQL `documents` 表（存元数据 + 状态）

**实现位置**：

- 路由：`src/gateway/knowledge-routes.ts` → `POST /api/v1/admin/knowledge/upload`
- 上传处理：`src/services/document-upload.ts`
- 拆块 + 索引：`src/rag/ingest.ts`
- 模型：`src/models/Document.ts`

**关键代码**：

```typescript
// 同步处理版本（不引入队列）
router.post(
  '/api/v1/admin/knowledge/upload',
  jwtAuth,
  koaBody({ multipart: true }),
  async (ctx) => {
    const file = ctx.request.files?.['file'];
    const tenantId = ctx.state.user.tenant_id;

    // 1. 文件落地
    const destPath = await saveUpload(file, tenantId);

    // 2. 写 documents 表
    const doc = await Document.create({
      tenant_id: tenantId,
      status: 'indexing',
      file_path: destPath,
    });

    try {
      // 3. 同步跑索引
      await ingestDocument({ id: doc.id, tenantId, filePath: destPath });
      await Document.update({ status: 'ready' }, { where: { id: doc.id } });
      ctx.body = { id: doc.id, status: 'ready' };
    } catch (err) {
      await Document.update({ status: 'failed' }, { where: { id: doc.id } });
      throw err;
    }
  },
);
```

**验收**：

- 上传 .md 文件 → 几秒后状态变 `ready`
- Qdrant 里能查到对应向量
- 上传 .pdf → 文本提取 + 索引成功

### C3 · 提示词配置

**需求**：每个租户自定义系统提示词；可版本管理。

**对应 Step**：Step 7

**使用技术**：

- 文件版本化（`shared/prompts/customer-service/system.v1.ts` / `v2.ts` / ...）
- 租户级覆盖（`tenants.settings.prompt_version` 字段）
- git 管理（每次改动走 PR + 评测验证）

**实现位置**：

- 提示词文件：`shared/prompts/customer-service/system.v*.ts`
- 加载逻辑：`src/lib/load-prompt.ts`
- 租户设置：`tenants.settings` JSON 字段

**关键代码**：

```typescript
// src/lib/load-prompt.ts
export async function loadSystemPrompt(tenantId: string): Promise<string> {
  const tenant = await Tenant.findByPk(tenantId);
  const version = tenant?.settings?.prompt_version ?? 'v1';
  const prompt = await import(`@shared/prompts/customer-service/system.${version}.ts`);
  return prompt.SYSTEM_PROMPT.replace('{tenantName}', tenant!.name);
}
```

**验收**：

- 租户 A 提示词 = 「你是 X 公司的客服」，租户 B 提示词 = 「你是 Y 公司的客服」
- 改 `system.v2.ts` 提交到 git，部署后所有租户切到 v2

### C4 · 模型选择

**需求**：主对话模型可换（Claude / 智谱 / DeepSeek / Moonshot），都走 Anthropic 协议。

**对应 Step**：Step 5

**使用技术**：

- **Vercel AI SDK**（`ai` + `@ai-sdk/anthropic`）：**主用**，`streamText()` 一句拿流式 + 工具循环
- @anthropic-ai/sdk：作为 `@ai-sdk/anthropic` 的传递依赖；高级场景（如 `cache_control` 自定义）可直接调
- 切换只改 `@ai-sdk/anthropic` 的 model 参数；切多供应商换 `@ai-sdk/openai` 等

**实现位置**：

- 配置：`src/config.ts`（读 `ANTHROPIC_API_KEY`）
- 客户端初始化：`src/lib/llm.ts`（导出 `anthropic('claude-sonnet-4-5')` provider）

**关键代码**：

```typescript
// src/lib/llm.ts
import { anthropic } from '@ai-sdk/anthropic';

export const llm = anthropic('claude-sonnet-4-5');

// 在 streamText 里用
import { streamText } from 'ai';

const result = streamText({
  model: llm,
  system: systemPrompt,
  messages,
});
```

**验收**：

- 改 `@ai-sdk/anthropic` 的 model 为 `'glm-4.5'`（智谱）→ 仍能正常对话（Anthropic 协议兼容）
- 跑评测集不漏一条
