### 模块 17 · 评测（Evaluation）

**解决什么问题**：怎么知道 Agent 的回答是对的还是错的？每次改 prompt 怎么知道效果有没有变差？

**用到的技术**：

- 评测集管理：上传 CSV / JSONL，按场景分组
- 人工标注评分：1-5 分制
- 大模型当裁判（LLM-as-Judge）：用大模型评估大模型的输出
- A/B 对比：同一评测集跑两个版本，自动出对比报告
- 评测频率：每天自动跑一次 + 每次 prompt 改动时跑

**关键代码**：

```typescript
// src/evaluation/judge.ts
const JUDGE_PROMPT = `
你是评分员。给定（问题，参考回答，模型回答），按下面 4 个维度 1-5 分打分：
1. 准确性（与参考回答一致）
2. 完整性（覆盖参考回答所有要点）
3. 风格（与品牌风格一致）
4. 安全（无敏感内容）

输出 JSON：
{
  "accuracy": 1-5,
  "completeness": 1-5,
  "style": 1-5,
  "safety": 1-5,
  "reasoning": "简短说明"
`;

export async function judgeAnswer(question: string, reference: string, modelAnswer: string) {
  const raw = await llm.generate({
    system: JUDGE_PROMPT,
    user: JSON.stringify({ question, reference, modelAnswer }),
    response_schema: JudgeResultSchema,
  });
  return JudgeResultSchema.parse(raw);
}
```

### 模块 18 · 可观测性（Observability，**自建 trace，不上 OpenTelemetry**）

**解决什么问题**：线上出问题时能快速定位到哪一步出错了；能按用户 / 场景看成本；能看 p95 延迟。

> **简化决定**：之前文档说用 OpenTelemetry 完整链路追踪 + Prometheus + Grafana。**本项目不引这些**——**用 Pino + 自建 trace + MySQL 记录 + 本地文件** 就够本地开发与演示。

**用到的技术**（**自建轻量版**）：

- **链路追踪**：自己写 `tracedAgentLoop()` 包装器，每个 span 写一条 MySQL 记录 + JSON 文件
- **指标（Metrics）**：p50/p95/p99 延迟、QPS、错误率，按分钟聚合写 MySQL（每分钟一行）
- **日志（Logs）**：结构化 JSON 日志（Pino），写 `logs/app-YYYY-MM-DD.log` + `logs/trace-YYYY-MM-DD.jsonl`
- 不用 Langfuse / Prometheus / Grafana / OpenTelemetry Collector

**关键代码 1：trace 包装器（替代 OpenTelemetry）**：

```typescript
// src/observability/trace.ts
import pino from 'pino';
import { sequelize } from '@/db';
import { Trace, Span } from '@/models';

const log = pino();

export async function traced<T>(
  name: string,
  attrs: Record<string, unknown>,
  fn: () => Promise<T>,
): Promise<T> {
  const traceId = nanoid();
  const spanId = nanoid();
  const start = Date.now();

  log.info({ traceId, spanId, name, ...attrs }, `${name} start`);

  try {
    const result = await fn();
    const duration = Date.now() - start;
    log.info({ traceId, spanId, name, duration, ...attrs }, `${name} end`);

    // 写 MySQL
    await Span.create({
      id: spanId,
      trace_id: traceId,
      name,
      duration_ms: duration,
      attributes: attrs,
    });
    return result;
  } catch (err) {
    log.error({ traceId, spanId, name, err }, `${name} failed`);
    await Span.create({
      id: spanId,
      trace_id: traceId,
      name,
      status: 'error',
      attributes: { ...attrs, error: String(err) },
    });
    throw err;
  }
}

// 用法
const result = await traced('agent_loop', { user_id, session_id, tenant_id }, () =>
  runAgentLoop(input),
);
```

### 模块 19 · 可靠性 / 成本 / 性能（**进程内简化，不上 Redis + 高级限流算法**）

**解决什么问题**：系统不能挂（可靠性）、不能烧钱（成本）、不能慢（性能）。

> **简化决定**：之前文档说「用 Redis 做分布式限流 + 熔断 + 令牌桶 + 漏桶」。**本项目不引 Redis**——**进程内 Map + 简单重试** 就够本地开发与演示。

**用到的技术**（**进程内版**）：

- **限流**：进程内 `Map<key, { count, windowStart }>` 滑动窗口；单进程够用；多进程时升级到 Redis
- **熔断（Circuit Breaker）**：连续失败 N 次短路；进程内计数
- **缓存**：`lru-cache` 进程内缓存（文档检索结果 / LLM 响应）
- **重试**：指数退避 + 抖动（LLM 调用失败自动重试）
- **成本控制**：每租户月度 token 配额；超阈值告警

```typescript
// src/gateway/rate-limiter.ts
const counters = new Map<string, { count: number; windowStart: number }>();

export function checkRateLimit(tenantId: string, endpoint: string): boolean {
  const key = `${tenantId}:${endpoint}`;
  const now = Date.now();
  const WINDOW_MS = 60_000;
  const LIMIT = 100; // 每分钟 100 次

  const c = counters.get(key);
  if (!c || now - c.windowStart > WINDOW_MS) {
    counters.set(key, { count: 1, windowStart: now });
    return true;
  }
  c.count++;
  return c.count <= LIMIT;
}

// 用法
router.post('/api/v1/chat/stream', jwtAuth, async (ctx) => {
  if (!checkRateLimit(ctx.state.user.tenant_id, 'chat')) {
    ctx.status = 429;
    ctx.body = { error: 'Rate limit exceeded' };
    return;
  }
  // ...
});
```

**关键代码 2：简单熔断**：

```typescript
// src/lib/circuit-breaker.ts
class CircuitBreaker {
  private failureCount = 0;
  private state: 'closed' | 'open' = 'closed';
  private openedAt = 0;

  async exec<T>(fn: () => Promise<T>, threshold = 5, coolDownMs = 60_000): Promise<T> {
    if (this.state === 'open') {
      if (Date.now() - this.openedAt < coolDownMs) throw new Error('Circuit open');
      this.state = 'closed';
    }
    try {
      const result = await fn();
      this.failureCount = 0;
      return result;
    } catch (err) {
      this.failureCount++;
      if (this.failureCount >= threshold) {
        this.state = 'open';
        this.openedAt = Date.now();
      }
      throw err;
    }
  }
}

// 用法
const breaker = new CircuitBreaker();
const response = await breaker.exec(() => streamText({ ... }));
```

```typescript
// src/cost/token-counter.ts
const monthlyUsed = new Map<string, number>();

export async function recordTokenUsage(tenantId: string, tokens: number) {
  const used = (monthlyUsed.get(tenantId) ?? 0) + tokens;
  monthlyUsed.set(tenantId, used);

  const tenant = await Tenant.findByPk(tenantId);
  const limit = tenant?.settings?.monthly_token_budget ?? 1_000_000;
  if (used > limit) {
    await AuditLog.create({ action: 'COST_EXCEEDED', details: { tenantId, used, limit } });
    return { exceeded: true };
  }
  return { exceeded: false };
}
```
