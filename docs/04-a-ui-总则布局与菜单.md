# 04-a · UI 需求 · 设计总则、布局与菜单

> **本文件是 `04-UI需求.md` 的 §0-§2 节**（原主文件已拆分为 04-a / 04-b / 04-c / 04-d 四份）。本份负责**设计总则 / 整体布局 / 菜单设计**。

## 0. 设计总则

### 0.1 技术选型

| 项       | 选型                                              | 落地情况                    |
| -------- | ------------------------------------------------- | --------------------------- |
| 组件库   | **Ant Design 6**                                  | ✅ 已用（注意 v6 的废弃 API） |

| 图表     | ECharts（`echarts-for-react`）                    | ✅                          |
| Markdown | react-markdown + remark-gfm + highlight.js        | ✅ 2026-10-25 全接上（`web/components/Markdown.tsx`）|
| 实时通信 | SSE（`fetch` + ReadableStream）                   | ✅（走 AI SDK 的 `useChat`）  |
| 时间     | Day.js（AntD 配套）                               | ✅                          |
| 图标     | `@ant-design/icons`                               | ✅                          |

| 错误兜底 | react-error-boundary                              | ✅ 2026-10-25 接上（`web/components/ErrorBoundary.tsx`）|

> ⚠️ **版本号以前写的是 AntD 5 / React Router 6** —— 实际已经是 AntD 6 / RR 7 / React 19。
> 「⚠️ 装了没用」的那几行不是笔误，是**选型表里写了但代码里没落地**的

> 但全库搜不到 import）。

### 0.2 主题与色彩

| Token          | 值         | 用途                |
| -------------- | ---------- | ------------------- |
| `colorPrimary` | `#2f54eb`  | 主题蓝（AntD 极客蓝） |
| `colorSuccess` | `#52c41a`  | 成功 / 已索引       |
| `colorWarning` | `#faad14`  | 警告 / 索引中       |
| `colorError`   | `#ff4d4f`  | 错误 / 失败         |
| `borderRadius` | `8`        | 通用圆角            |
| `fontSize`     | `14`       | 基础字号            |

> ⚠️ **2026-10-27 订正：这张表以前跟代码对不上**（写的还是 AntD 默认值
> `#1677ff` / `borderRadius: 6`）。**代码是刻意这么选的，不是笔误** ——
> 主色选了更沉稳的极客蓝 `#2f54eb`（比 AntD 默认蓝压得住深色侧栏），
> 圆角选了 8（跟 §1.3「圆角 8」一致）。
> **唯一真源是 `web/theme.ts` 的 `brandToken`**，改设计先改那里
> （docs/04-b §4.2 也确认「theme 才是真理来源」）。

- **支持深色模式**（AntD `theme.darkAlgorithm`），右上角切换
- 浅色为默认

> **整页不引用任何图片资源**。UI 装饰元素（icon / logo / avatar / 占位）一律用 **AntD 图标**（`@ant-design/icons`）替代。

| 场景         | 不要                   | 改用                                                                                  |
| ------------ | ---------------------- | ------------------------------------------------------------------------------------- |
| 公司 Logo    | `image: 'logo.png'`    | `<Avatar shape="circle" style={{ background: token.colorPrimary }}><RobotOutlined /></Avatar>`（实现见 `web/components/shell/BrandMark.tsx`，背景是 `colorPrimary` → `colorPrimaryHover` 的渐变） |
| 用户头像     | `image: avatar.png`    | `<Avatar icon={<UserOutlined />} />`（无头像时）                                      |
| 文件类型图标 | `image: file-icon.png` | `<FilePdfOutlined />` / `<FileTextOutlined />`（按扩展名选）                          |
| 占位插画     | `image: empty.png`     | AntD `<Empty />`（自带 SVG）                                                          |
| 状态指示     | `image: success.png`   | AntD `<Badge status="success" />` / `<CheckCircleOutlined />`                         |
| 操作按钮图标 | `image: button.png`    | AntD `icon` prop（如 `<Button icon={<DeleteOutlined />}>删除</Button>`）              |

**例外（这些是真内容，不是 UI 装饰）**：

- 用户上传的文档预览（PDF 第一页缩略图）

> 例外里的图片用 `<img>` 标签或 AntD `<Image>` 组件展示；其余一律 AntD 图标。

## 1. 整体布局

### 1.1 后台管理布局（`<AdminLayout />`）

```
┌─────────────────────────────────────────────────────────┐
│ Header（高 56px）                                       │
│ ☰ 折叠 / 展开 │ 角色说明              │ [👤 用户菜单] │
├──────────┬──────────────────────────────────────────────┤
│ Sider    │ Content（铺满）                              │
│ (240px)  │                                              │
│ 折叠后 64│  页面标题                                     │
│ 菜单     │  主内容                                       │
│         │                                              │
│ 📊 看板  │                                              │
│ 📚 知识库 │                                               │
│ 🤖 模型  │                                               │
│ 🛠 工具  │                                               │
│ 📈 评测  │                                               │
│ 📊 观测  │                                               │
│ 👥 用户  │                                               │
│ ⚙ 设置  │                                               │
└──────────┴──────────────────────────────────────────────┘
```

- **Header**：左 折叠按钮 + 角色说明；右 用户菜单（邮箱、登出）。全局搜索、通知、主题切换在对应功能落地前不渲染占位按钮
- **Sider**：只放已经落地的菜单；折叠状态存 localStorage
- **Content**：页面标题 + 主内容。面包屑由各页自己的标题区决定，壳层不另画一条

### 1.2 聊天挂件布局（`<WidgetLayout />`）

```
┌─────────────────────────────────┐
│ 🏢 公司 Logo  客服 · 在线        │ ← Header（40px，可关闭）
├─────────────────────────────────┤
│ ┌─────┐ ┌─────────────────────┐ │
│ │历史 │ │                      │ │
│ │会话 │ │  消息列表             │ │
│ │(可  │ │  （按时间倒序）       │ │
│ │折叠)│ │                      │ │
│ │     │ │  ▢ 思考模式 ✓         │ │
│ │     │ │                      │ │
│ │     │ │  [输入框] [发送]          │
│ │     │ │  [思考] [文件]          │ ← 输入框上方 toggle
│ └─────┘ └─────────────────────┘ │
└─────────────────────────────────┘
```

- **紧凑模式**：边距更小、字号略小、AntD 主题 token 临时覆盖
- **可隐藏历史侧栏**：默认隐藏，点了历史按钮展开
- **可关闭整个挂件**：右上角 × 按钮（嵌入网页时使用）

### 1.3 公开页面布局

- 登录页：全屏居中卡片（白底，圆角 8，阴影 4）
- 404 / 500：全屏居中 `<Result />` + 按钮

## 2. 菜单设计

### 2.1 SaaS 平台方菜单（`/system/*`）

```
📊 总览
  └─ 总览页 (KPI、租户数、告警)

🏢 租户
  └─ 租户列表
       └─ 创建租户（弹窗 Drawer）

⚙ 系统
  └─ 平台方账号（改密码）
```

### 2.2 租户后台菜单（`/admin/*`）

```
📊 看板
  └─ Dashboard（关键指标 + 异常告警）

📚 知识库
  ├─ 文档管理（P8 · 列表 + 块数 + 上传 + 状态 + 重新索引）✅
  ├─ 检索测试（输入问句，看 top N 命中的片段）★ 关键 ✅
  └─ 切片浏览（看一篇文档被切成的每一块 · 诊断用）✅ 2026-10-27

🤖 模型 & 提示词
  ├─ 模型选择（C4 · 当前供应商 + 备选）
  └─ 提示词配置（C3 · 文件编辑器 + 版本切换）

🛠 工具（C2 · ✅ 已落地 2026-10-25）
  ├─ 工具列表（`/admin/tools`）✅
  └─ 工具调用记录（`/admin/tool-logs`）✅

📈 评测
  ├─ 评测集（P6 · 上传 + 列表）
  ├─ 评测结果（P7 · 分数 + 趋势 + 裁判理由）
  └─ 版本对比（A/B · 两次跑批并排看 · ✅ 已落地 2026-10-26）

📊 观测
  ├─ Trace 列表（P4 · 按时间 / 用户 / 状态筛选）
  │   └─ Trace 详情（时间线 + 单步详情）
  ├─ 成本分析（P5 · 按用户 / 场景 / 模型拆解）
  └─ 告警规则

👥 用户
  ├─ 用户列表（P10 · 含创建 / 改 / 删 / 重置密码）
  ├─ 用户记忆（B4 · 左用户右记忆，看每个用户的长期记忆）✅
  └─ 操作审计

⚙ 设置
  ├─ 租户配置（E2 · 限额 / 告警阈值）
  ├─ 安全（D4 · 注入 / 审核 / 脱敏开关）
  └─ API 密钥
```

> **预留菜单项**：未来要加的功能（比如「协作 / 团队管理 / 计费」）菜单位置已经留好，加新菜单项就行。

### 2.3 前台聊天挂件（无菜单）

公开挂件是单页面，不需要侧栏菜单：

- 主区：聊天界面
- 隐藏侧栏：会话历史列表（点了展开）
- 用户头像菜单：登录 / 退出 / 历史记录

> **但「租户前台」（`/customer/*`）是有侧栏的** —— 那是登录后的用户中心，
> 不是公开挂件。侧栏三项：

```
🏠 首页（B7 · 用户中心工作台：欢迎语 / 推荐问题 / 最近会话 / 知识库 / 我的记忆）✅
💬 智能问答（B1 · 对话本体）
📖 我的记忆（B4 · 看 / 改 / 关掉自动记忆）✅
```

> ⚠️ **首页和智能问答是两个页面**（2026-10-24 之前是两个 URL 指向同一个组件）。
> 首页是概览 + 入口，聊天页是纯对话 —— 详见 [04-b](./04-b-UI-登录与聊天挂件.md) §4.10。
