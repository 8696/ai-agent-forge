## C. 前端技术栈

### C.1 框架与库

| 选型                | 版本       | 用途                  | 理由                                                                           |
| ------------------- | ---------- | --------------------- | ------------------------------------------------------------------------------ |
| Vite                | 8.x        | 构建工具 + 开发服务器 | 启动秒开；HMR 快；纯客户端渲染，没有 SSR                                       |
| React               | 19.x       | 视图层                | 函数组件 + Hooks；AntD v6 配套（v6 已对齐 React 19）                          |
| TypeScript          | 5.6        | 类型                  | 与后端共用类型                                                                 |
| **Ant Design 6**    | 6.6.6      | 组件库                | 国内业务后台首选；组件齐全（Table / Form / Modal / Layout 全有）；支持主题定制。**注意：是 v6 不是 v4/v5，API 有变化（见 C.7）** |
| React Router DOM    | 7.x        | 路由                  | 客户端路由；管理后台的菜单跳转                                                 |
| Axios               | 1.x        | HTTP 请求             | 请求带 token / 错误统一处理                                                    |
| Zustand             | 5.x        | 客户端状态            | 比 Redux 轻                                                                    |
| Day.js              | 1.x        | 时间处理              | AntD 内置 dayjs；这里引独立版做 DatePicker 等需要                              |
| `@ant-design/icons` | 6.x        | 图标                  | AntD 官方图标库                                                                |

**为什么选 AntD 而不是 shadcn/ui / Tailwind**：

- 组件齐全：管理后台要用的 Table、Tree、Transfer、Cascader、Form、Drawer，AntD 一个包搞定；用 shadcn/ui 要拼 Radix + Tailwind + 一堆插件
- 中文文档 + 中文社区：国内项目，搜「AntD 表格分页」能直接找到答案
- 主题按品牌定制：`ConfigProvider` 改 token，整个应用的色调、字号、圆角一起改

### C.2 目录组织（web/ 内部）

> 按职责拆分；具体页面和组件的细化按需增减，这里只列主要入口。
> **三套子系统（system / admin / customer）独立 Layout 与 page 目录**的完整结构详见 `03-b-技术栈-后端栈.md` §B.5.6。

```
web/
├── main.tsx                # React 入口
├── App.tsx                 # 路由根 + AntD ConfigProvider
├── routes.tsx              # 路由表
├── pages/
│   ├── widget/             # 聊天挂件页面（公开）
│   └── admin/              # 管理后台（需登录）
├── components/             # 通用组件（封装 AntD）
├── lib/                    # API 调用、状态管理
└── styles/                 # 全局样式
```

主要页面（`pages/admin/`）：

| 页面                             | 用途                    |
| -------------------------------- | ----------------------- |
| `DashboardPage`                  | 关键指标 + 异常告警     |
| `TracesPage` / `TraceDetailPage` | Trace 列表 + 详情       |
| `CostPage`                       | 成本看板                |
| `EvalPage`                       | 评测集管理 + 评测结果   |
| `KnowledgePage`                  | 文档上传 + 检索效果预览 |
| `ToolsPage`                      | 工具注册 / 启停         |
| `TenantsPage`                    | 租户管理（多租户场景）  |
| `LoginPage`                      | 管理员登录              |

### C.6 聊天挂件的特殊处理

聊天挂件是嵌入客户网站的小窗口，跟管理后台是同一份前端代码，但走不同入口：

- 挂件走 `/widget/:tenantId`，加载极简样式（AntD 主题临时覆盖为紧凑版）
- 挂件状态靠 URL 传 tenant，**不做鉴权**（公开）
- 挂件内不显示管理后台导航

### C.7 AntD v6 行为差异（**写代码前必读**）
