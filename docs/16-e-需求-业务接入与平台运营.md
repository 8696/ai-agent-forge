## F · SaaS 平台运营（SaaS 系统方专属）

### F1 · System 端管理租户列表 + 重置租户 admin 密码

**需求**：SaaS 平台方（system user）能列出所有租户、看每个租户的基本信息，并能重置每个租户初始 admin 账号的密码（admin 账号是 system 在建租户时自动创建的）。

**对应 Step**：Step 13（后台管理 UI 的 system 部分）

**端点清单**（详见 src/gateway/system/tenant-routes.ts）：

| 方法  | 路径                                              | 用途                         | 鉴权              |
| ----- | ------------------------------------------------- | ---------------------------- | ----------------- |
| GET   | `/api/v1/system/tenants`                          | 列所有租户（含 admin email） | requireSystemUser |
| GET   | `/api/v1/system/tenants/:id`                      | 单个租户详情                 | requireSystemUser |
| PATCH | `/api/v1/system/tenants/:id`                      | 改 name / plan               | requireSystemUser |
| POST  | `/api/v1/system/tenants/:id/admin/reset-password` | 重置租户 admin 密码          | requireSystemUser |

**重置密码请求体**：`{ "new_password": "new123456" }`。后端会自动：1) bcrypt 哈希 2) 置 must_change_password=true（admin 重新登录会强制改密）。

**验收**：

- `GET /tenants` 返回所有租户，每条带 admin email
- `PATCH /tenants/:id` body={name, plan} 成功更新
- `POST /tenants/:id/admin/reset-password` body={new_password: "new123456"} → admin password_hash 更新 + must_change_password=true
- 跨子系统防御：admin token 调 `/api/v1/system/tenants` → 401（requireSystemUser 拒）

### F2 · 平台方：修改租户到期时间 + 禁用 / 启用租户

**需求**：SaaS 平台方（system user）能改租户的到期时间（`expires_at`，NULL = 永不过期），也能禁用 / 启用租户。被禁用的租户、或已到期的租户，在 `admin/login` 和 `customer/login` 端点都返回 401（**统一响应「租户不可用」，不区分禁用 / 到期**，防账号枚举 + 防泄漏租户内部状态）。

**对应 Step**：Step 15

**使用技术**：

- MySQL `tenants` 表加 `expires_at`（`DATETIME(6) NULL`）+ `status`（`ENUM('active','disabled') DEFAULT 'active'`）
- Koa 路由：2 个子资源 PATCH 端点（与 F1 的 PATCH `/tenants/:id` 同文件、分桶）
- Zod 校验 + Audit Logs（写 `TENANT_EXPIRES_CHANGE` / `TENANT_STATUS_CHANGE`）
- 登录拦截：`admin/login` + `customer/login` 在校验租户后**多走一道**租户状态闸门
- 防御自锁：禁用的「系统初始租户」（`code='system'`）拒绝 PATCH `status=disabled`
- 跨子系统防御：复用 `requireSystemUser`（`role='system'` 才能调）

**实现位置**：

- 数据模型：`05-a-数据模型-mysql.md` §5.1 `tenants` 表 DDL 新增 2 列
- 模型：`src/models/Tenant.ts` 加 `expires_at` / `status` 字段（`src/migrations/` 同步加 umzug 迁移）
- 路由：`src/gateway/system/tenant-routes.ts` 新增 2 个 PATCH：
  - `PATCH /api/v1/system/tenants/:id/expires_at`
  - `PATCH /api/v1/system/tenants/:id/status`
- 登录拦截：`src/gateway/admin/auth-routes.ts` + `src/gateway/customer/auth-routes.ts` 在 `Tenant.findOne` 之后、`User.findOne` 之前加闸门（否则用户都查不到，泄漏面更小）
- 审计：`src/lib/audit-log.ts` 的 `writeAuditLog(...)`，`tenant_id` 传 NULL（系统级日志）
- 前端：`web/pages/system/TenantsPage.tsx` 列表加 status / expires_at 列；行的「操作」加「修改到期」「启停」按钮（AntD Modal + DatePicker + Switch）

**关键代码**：

```typescript
// src/gateway/system/tenant-routes.ts
import { Tenant } from 'src/models/Tenant';
import { writeAuditLog } from 'src/lib/audit-log';

const expiresAtSchema = z.object({
  expires_at: z.string().datetime().nullable(), // ISO8601；null = 取消到期
});
const tenantStatusSchema = z.object({
  status: z.enum(['active', 'disabled']),
});

systemTenantRouter.patch('/tenants/:id/expires_at', jwtAuth, requireSystemUser, async (ctx) => {
  const id = ctx.params.id;
  const { expires_at } = expiresAtSchema.parse(ctx.request.body);
  const tenant = await Tenant.findByPk(id);
  if (!tenant) throw new NotFoundError('租户不存在');

  await tenant.update({ expires_at });
  await writeAuditLog({
    tenant_id: null,
    user_id: ctx.state.systemUser.id,
    action: 'TENANT_EXPIRES_CHANGE',
    resource_type: 'tenant',
    resource_id: id,
    details: { expires_at },
  });
  ctx.body = { ok: true, expires_at };
});

systemTenantRouter.patch('/tenants/:id/status', jwtAuth, requireSystemUser, async (ctx) => {
  const id = ctx.params.id;
  const { status } = tenantStatusSchema.parse(ctx.request.body);
  const tenant = await Tenant.findByPk(id);
  if (!tenant) throw new NotFoundError('租户不存在');

  // 防自锁：系统初始租户不能被禁用，否则 SaaS 平台方自己也登不进
  if (tenant.code === 'system' && status === 'disabled') {
    throw new ValidationError('不能禁用系统初始租户');
  }

  await tenant.update({ status });
  await writeAuditLog({
    tenant_id: null,
    user_id: ctx.state.systemUser.id,
    action: 'TENANT_STATUS_CHANGE',
    resource_type: 'tenant',
    resource_id: id,
    details: { status },
  });
  ctx.body = { ok: true, status };
});

// src/gateway/customer/auth-routes.ts（在 Tenant.findOne 之后立刻闸门——不查询 User）
const tenant = await Tenant.findOne({ where: { code: input.tenant_code } });
if (tenant === null) throw new AuthError('租户不可用'); // 跟禁用到期同响应，防枚举
const now = new Date();
if (tenant.status === 'disabled' || (tenant.expires_at !== null && tenant.expires_at <= now)) {
  throw new AuthError('租户不可用'); // 统一 401，不区分禁用 / 到期
}
```

**响应格式**：`PATCH` 成功 → `{ ok: true, expires_at: '...' }` 或 `{ ok: true, status: 'active' }`。`expires_at` 是 ISO8601 字符串；前端用 Day.js 格式化。

**审计可查**：每条改动都会在 `audit_logs` 表留痕，能查「哪个 system user 在什么时候改了哪个租户」。`tenant_id` 写 NULL（这是系统级操作，不属于任何租户）。

**验收**：

- `PATCH /tenants/{id}/expires_at` body={expires_at: '2026-12-31T15:00:00Z'} → tenants.expires_at 更新；audit_logs 写一条 TENANT_EXPIRES_CHANGE
- `PATCH /tenants/{id}/expires_at` body={expires_at: null} → 清空到期时间（永不过期）
- `PATCH /tenants/{id}/status` body={status: 'disabled'} → tenants.status 改为 disabled；audit_logs 写一条 TENANT_STATUS_CHANGE
- 禁用租户后，`admin/login` + `customer/login` → 401「租户不可用」（与「邮箱或密码错误」**完全同响应体**）
- 到期租户登录 → 401「租户不可用」（同上，统一）
- 改回 `active` + 清空到期 → 立即可登录（不需要重启服务）
- 跨子系统防御：admin token 调 `PATCH` → 401（`requireSystemUser` 拒）
- 防自锁：`PATCH` 禁用 `code='system'` 的初始租户 → 400「不能禁用系统初始租户」
- `GET /tenants` 返回值带 `status` + `expires_at` 字段
