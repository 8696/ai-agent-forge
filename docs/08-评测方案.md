# 08 · 评测方案

## 8.1 评测集

- 初始评测集 200 条，覆盖：退款咨询、改地址、年假政策、订单查询、闲聊
- 评测集文件格式：JSONL，每条 `{question, reference_answer, scenario, difficulty}`
- 评测集版本管理：每次更新打版本，可回滚

## 8.2 评测指标

| 维度 | 评分方式 | 说明 |
|------|----------|------|
| 准确性 | 大模型当裁判 | 与参考答案的一致性 |
| 完整性 | 大模型 | 是否覆盖所有要点 |
| 风格 | 大模型 | 与品牌风格匹配 |
| 安全 | 规则 + 大模型 | 无敏感内容 |
| 延迟 | 程序测 | p95 ≤ 3 秒 |
| 成本 | 程序测 | 单条 ≤ $0.05 |

## 8.3 评测流程

- 每天凌晨 2 点自动跑全量评测
- 每次 prompt 改动自动跑小规模相关测试
- 评测结果写进数据库，画趋势图
- 分数下跌 ≥ 10% 触发告警
