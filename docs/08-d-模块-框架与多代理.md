### 模块 13 · Agent 框架对比

**解决什么问题**：手写循环能跑通，但项目大了需要框架的工程能力（状态持久化、断点恢复、可观测性）。

**用到的技术**：

- LangGraph：用图描述代理流程
- 状态持久化、内置 HITL、可视化

**选型**：手写循环为生产主用，LangGraph 用于复杂工作流场景。对比文档写在 `/docs/wiki/framework-comparison.md`。

> **本项目实际做法**：用 **Vercel AI SDK** 作为 Agent 框架（提供 `streamText` / `tool()` / 自动循环）。**不**用 LangGraph、不对比其他框架。详见 `08-b-模块-工具与agent.md` 模块 07。

### 模块 14 · 多代理协作（Multi-Agent）

**解决什么问题**：单一代理处理复杂任务时上下文太长、专业度不够，需要拆给多个专业代理。

**用到的模式**：

- 监督者模式（Supervisor Pattern）：监督者拆任务给子代理，子代理完成后返回
- Agent Handoff（任务移交）：子代理 A 把控制权交给子代理 B
- Shared State（共享状态）：多个子代理读同一份上下文

**关键代码**：

```typescript
// src/agent-orchestrator/supervisor.ts
export async function runSupervisor(input: SupervisorInput) {
  const sharedState: SharedState = {
    user_message: input.message,
    user_context: input.userContext,
    intermediate_results: {},
  };

  while (true) {
    // 监督者决策：下一个子代理是谁
    const decision = await supervisor.decide(sharedState);

    if (decision.action === 'finish') {
      return { message: decision.final_message, state: sharedState };
    }

    // 调用子代理
    const subResult = await callSubAgent(decision.next_agent, sharedState);
    sharedState.intermediate_results[decision.next_agent] = subResult;

    // 检查是否有子代理要 handoff
    if (subResult.handoff_to) {
      decision.next_agent = subResult.handoff_to;
    }
  }
}
```

**子代理分工**：

- 客服代理：主对话、回答用户
- 研究代理：调 RAG、查文档
- 操作代理：调外部系统
- 审核代理：敏感操作二次确认

> **本项目 MVP 不做**多代理——单代理 + RAG + 记忆 已能跑通客服场景。模块 14 仅做**概念说明**，Phase 2+ 再考虑。

### 模块 15 · 浏览器代理（Browser Agent）

**在本项目的位置**：只用于「操作公司内部 SaaS 后台」这种无法用 API 接入的场景。

**用到的工具**：

- Playwright（无头浏览器自动化）
- Accessibility Tree（无障碍树）作为页面摘要，比 DOM 短、噪音少

**关键代码**：

```typescript
// src/tools/browser/playwright-tool.ts
export const browserTools = {
  navigate: {
    name: 'browser_navigate',
    description: '打开指定网址',
    execute: async ({ url }: { url: string }) => {
      const page = await browser.newPage();
      await page.goto(url);
      return await getAccessibilitySnapshot(page);
    },
  },
  click: {
    name: 'browser_click',
    description: '点击页面上指定 ref 的元素',
    execute: async ({ ref }: { ref: string }) => {
      await page.click(`[aria-ref="${ref}"]`);
      return await getAccessibilitySnapshot(page);
    },
  },
  extract: {
    name: 'browser_extract',
    description: '按选择器提取文本',
    execute: async ({ selector }: { selector: string }) => {
      return await page.locator(selector).allTextContents();
    },
  },
};
```

> **本项目 MVP 不做** Browser Agent——只保留设计稿；外部系统接入走 API / MCP，不靠浏览器自动化。
