## 13.1 各文档的职责

> **拆分规则**：单份文件超过 ~500 行（或逻辑边界清晰）时，用**字母后缀**拆成子文件，命名形如 `04-a-ui-xxx.md`、`07-b-工具与agent.md`。

## 13.2 怎么新增一条需求

**唯一位置**：`12-需求技术对照表.md`（其他文件不再写需求清单）

步骤：

1. **打开 `12-需求技术对照表.md`**
2. **找到对应的 A / B / C / D / E 章节**
3. **按下面的模板加一条**
4. **在 12 末尾的「按需求 ↔ 技术」索引里同步加**
5. **不需要在 `01-需求与场景.md` 里加**，因为 01 已经指向 12

### 需求命名约定

| 前缀 | 类别         |
| ---- | ------------ |
| `A*` | 多租户基础   |
| `B*` | AI 对话能力  |
| `C*` | 管理员可配置 |
| `D*` | 运维稳定     |
| `E*` | 业务接入     |

下一个编号看当前已有的最大编号往下排。

### 新增需求模板

```markdown
#### {前缀}{N} · {需求名}

**需求**：{一句话}

**对应 Step**：Step N / Step M

**使用技术**：

- {技术 1}
- {技术 2}

**实现位置**：

- {文件 / 路由 / 函数 1}
- {文件 / 路由 / 函数 2}

**关键代码**：
{关键模式代码}

**验收**：

- {怎么测 1}
- {怎么测 2}
```

## 13.5 状态追踪

每个文档 / 步骤 / 需求都可以标状态：

| 状态 | 标记 | 含义 |
|------|------|------|
| 未开始 | ⬜ | 文档 / 代码都还没动 |
| 进行中 | 🔄 | 正在改文档 / 写代码 |
| 已完成 | ✅ | 写完且通过验收 |

### 用法

- `12-需求技术对照表.md` 也可以加「实施状态」列
- 状态变更时：改 `⬜` 为 `🔄` 或 `✅`，并填完成日期

## 13.6 文档版本约定

- **大改一次**：在文档末尾加一行 `> 最后更新：YYYY-MM-DD`
- **不删旧内容** —— 改错了 git history 还能找回来
- **新加内容** 优先在「扩展点」追加，不重写已有部分

## 13.8 变更同步规则（**最重要 · 文档 = 系统规格**）

> **核心原则**：这份文档**不是**写完就完的「实施说明」，**而是**整个系统的**「规格定义」——文档改了，代码必须跟；代码改了，文档必须跟。
> 文档和代码是 **1:1 镜像关系**，任何一边脱节都是 bug。

### 13.8.1 改 X → 必须同步改 Y（按场景分）

### 13.8.4 「文档先行」原则

> **任何改动都先改文档，再改代码**。理由：
>
> 1. 文档是「规格」，代码是「实现」——规格错了实现就错
> 2. 改文档时容易发现需求漏洞；直接改代码容易埋雷
> 3. 改完文档后写代码，可以照着文档测试（**测试 = 文档自检**）

工作流：

```
1. 改 12-需求技术对照表.md
   ↓
2. 改 05-数据模型.md（如有表结构）
   ↓
3. 改 04-UI需求.md（如有 UI）
   ↓
4. 改 README.md（如新增文件）
   ↓
5. 跑「变更检查清单」打钩
   ↓
6. 改代码
```

## 13.9 命名 / 格式约定

- **主文档文件编号**两位数字（`01` 到 `13`），新增主文件用下一个编号
- **子文件**用「主编号 + 字母后缀」：`03-a-xxx.md` / `04-b-ui-xxx.md` / `07-f-模块-xxx.md`
  - 字母后缀小写（`a` / `b` / `c` / ...），按文档内章节顺序递增
  - **不**用数字后缀（`04-1` / `04-2`），按字母方便一眼看出顺序
  - **不**用 3 级嵌套（`04-a-1`），主编号 + 一层字母就够
- **需求编号**：字母 + 数字（A1 / B2 / ...）
- **Step 编号**：连续整数（Step 1 / 2 / ...）
- **模块编号**：两位数字 `00`-`23`（已学模块），`AI-N`（新模块）
- **代码示例**用 TypeScript（前后端都用）
- **日志 / 注释**用完整中文，不用黑话缩写
- **跨文件引用**：写「`12-需求技术对照表.md`」或「`12-a-需求-多租户与登录.md`」，**不要**写相对路径 `[12](./12-...md)`（避免拷贝时失效）
