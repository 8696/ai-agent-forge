### A.3 TypeScript 配置（双 tsconfig，路径别名分前后端）

```json
// tsconfig.json（后端）
{
  "compilerOptions": {
    "target": "ES2023",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "lib": ["ES2023"],
    "types": ["node"],
    "outDir": "./dist",
    "rootDir": "./src",
    "strict": true,
    "noUncheckedIndexedAccess": true,
    "noImplicitOverride": true,
    "noFallthroughCasesInSwitch": true,
    "exactOptionalPropertyTypes": true,
    "skipLibCheck": true,
    "esModuleInterop": true,
    "resolveJsonModule": true,
    "isolatedModules": true,
    "verbatimModuleSyntax": true,
    "paths": {
      "@shared/*": ["./shared/*"]
    }
  },
  "include": ["src/**/*", "shared/**/*"]
}

// tsconfig.web.json（前端）
{
  "extends": "./tsconfig.json",
  "compilerOptions": {
    "lib": ["DOM", "DOM.Iterable", "ES2023"],
    "types": ["vite/client"],
    "jsx": "react-jsx",
    "noEmit": true,
    "paths": {
      "@/*": ["./web/*"],
      "@shared/*": ["./shared/*"]
    }
  },
  "include": ["web/**/*", "shared/**/*"]
}
```

> **为什么 web/ shared/ 还要各放一个 tsconfig.json**：
>
> - WebStorm / VS Code 打开 `web/**/*.tsx` 时会向上找最近的 `tsconfig.json`，命中根目录那份（不带 JSX）会报 `TS6142: --jsx is not set`
> - 在 `web/` 和 `shared/` 下各放一个就近的 `tsconfig.json`（`web/` 那个 extends `./tsconfig.web.json`，`shared/` 那个 extends `./tsconfig.json`），IDE 就能解析到带 JSX / DOM lib 的正确配置
> - 实际构建仍走根目录 `tsc --noEmit -p tsconfig.web.json`，新增的子配置**不参与**构建，只给 IDE 用

### A.9 怎么用

- Docker Compose 自动起 MySQL 8.0 + Qdrant
- 写代码时编辑器按 Prettier + EditorConfig 自动格式化；提交前 Husky 自动跑 ESLint + typecheck
- `yarn lint` 跑全量 ESLint；`yarn format` 跑全量 Prettier；`yarn typecheck` 跑前后端类型检查

> ⚠️ **完整清单以 `.env.example` 为准**（**90 个变量**）。
> `src/config.ts` 的 zod schema 有 **97 个键**，差的这 7 个是**故意不写进 `.env.example`** 的：
> 6 个已经搬到租户后台的 `CHAT_*` 配置项（`CHAT_RETRIEVAL_TOP_K` / `CHAT_MAX_HISTORY_TURNS` /
> `CHAT_RETRIEVAL_TOKEN_BUDGET` / `CHAT_CONTEXT_TOKEN_BUDGET` / `CHAT_MAX_INPUT_CHARS` /
> `CHAT_THINKING_BUDGET_TOKENS`，在 `.env.example` 里只以注释形式出现）+ `QDRANT_COLLECTION`。
> **除这 7 个以外两边一一对应 —— 改一个必须改另一个**（`scripts/sync-env.ts` 同步）。
> 本节只列**分组 + 关键变量名**，便于按功能定位；变量名大小写敏感。

| 分组 | 关键变量 |
| ---- | -------- |
| 运行时 / 端口 | `NODE_ENV`、`PORT`（test 自动派生 3099，不跟 dev/prod 的 3000 冲突） |
| MySQL | `MYSQL_HOST`、`MYSQL_PORT`、`MYSQL_USER`、`MYSQL_PASSWORD`、`MYSQL_DB` |
| 向量库（Qdrant） | `QDRANT_URL`、`QDRANT_COLLECTION` |
| 上传 / 拆块 | `DATA_DIR`、`MAX_UPLOAD_BYTES`、`CHUNK_SIZE`、`CHUNK_OVERLAP`（800 / 150） |
| LLM provider 切换 | `LLM_PROVIDER`（minimax / zhipu / deepseek / qwen / custom）、`LLM_MODEL`、`LLM_EMBEDDING_MODEL` |
| 5 个 provider 的凭据 | 每个 provider 一组 `<PREFIX>_API_KEY` / `<PREFIX>_BASE_URL` / `<PREFIX>_MODEL` / `<PREFIX>_ANTHROPIC_BASE_URL` / `<PREFIX>_ANTHROPIC_MODEL`（前缀：`MINIMAX` / `ZHIPU` / `DEEPSEEK` / `QWEN` / `CUSTOM`） |
| Embedding（按 provider） | 每个 provider 的 `<PREFIX>_EMBEDDING_MODEL`（DeepSeek 无嵌入接口，该项留空） |
| 租户密钥加密 / SSRF | `CONFIG_ENCRYPTION_KEY`（**不配就禁止保存租户 apiKey**，且配了不能换）、`CONFIG_ALLOW_PRIVATE_LLM_ENDPOINT`（生产默认禁私网） |

| 会话摘要 | `CHAT_SUMMARY_ENABLED`、`CHAT_SUMMARY_TOKEN_BUDGET`、`CHAT_SUMMARY_TARGET_CHARS`、`CHAT_SUMMARY_MAX_INPUT_TOKENS`、`CHAT_SUMMARY_TIMEOUT_MS` |
| JWT | `JWT_SECRET`（**至少 32 字符**）、`JWT_EXPIRES_IN` |
| 安全（脱敏 / 敏感词 / 注入） | `SECURITY_SENSITIVE_WORDS_ENABLED`、`SECURITY_INJECTION_ENABLED`、`SECURITY_INJECTION_LLM_MODE`（confirm / always / off）、`SECURITY_OUTPUT_LLM_CHECK`、`SECURITY_GUARD_TIMEOUT_MS` |
| 租户隔离强制 | `TENANT_SCOPE_ENFORCE`（**平台级硬边界，不给租户开关**；默认开，出问题先关它止血） |
| 限流 | `RATE_LIMIT_ENABLED`、`RATE_LIMIT_WINDOW_MS`、`RATE_LIMIT_MAX_REQUESTS`、`RATE_LIMIT_MAX_REQUESTS_PER_USER` |
| 熔断 | `CIRCUIT_BREAKER_ENABLED`、`CIRCUIT_BREAKER_FAILURE_THRESHOLD`、`CIRCUIT_BREAKER_COOLDOWN_MS` |
| 重试 | ⚠️ **没有 env 变量** —— 重试参数（`maxRetries` / `initialDelayMs` / `maxDelayMs` / `backoffFactor`）是 `src/lib/retry.ts` 里的代码常量，由调用方传入 |
| 成本与预算 | `COST_TRACKING_ENABLED`、`COST_BUDGET_BLOCK`（默认只告警不拦）、`COST_PRICE_TABLE`（自定义价格表 JSON） |

| 观测 | `TRACE_ENABLED`、`TRACE_FILE_ENABLED`（另写 `logs/trace-YYYY-MM-DD.jsonl` 副本） |

### A.14 Conventional Commits 提交示例

```bash
# 新功能
git commit -m "feat: 加入 SSE 流式聊天支持"

# 修复 bug
git commit -m "fix: 修复会话历史 token 超限导致的崩溃"

# 文档
git commit -m "docs: 补充 14-前端代码示例"

# 重构（不改行为）
git commit -m "refactor: 把 trace 写入拆成独立中间件"

# 性能优化
git commit -m "perf: 给 messages 表加 idx_messages_tenant_created 索引"

# 测试
git commit -m "test: 补 Agent loop 的单元测试"
```

格式：`<type>: <中文一句话>`。type 必须是 `feat` / `fix` / `docs` / `style` / `refactor` / `perf` / `test` / `build` / `ci` / `chore` / `revert` 之一。

### A.16 MCP 服务目录约定

```
mcp-servers/
├── order-system/             # 订单系统 MCP
│   ├── package.json
│   ├── tsconfig.json
│   └── src/
│       ├── server.ts
│       └── tools/
│           ├── order-query.ts
│           └── order-update.ts
├── talentsystem/             # 工单系统 MCP
│   ├── package.json
│   └── tsconfig/
│       └── server.ts
└── README.md
```

主项目通过 `mcp-servers/order-system` 起一个独立的 stdio 进程来调用（详见本项目的「后端代码示例」§13.6）。
