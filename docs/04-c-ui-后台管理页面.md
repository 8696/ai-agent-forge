### 5.4 模型 & 提示词

#### 5.4.1 模型选择 `/admin/model`（C4）

- 当前模型：下拉框（Claude Sonnet / 智谱 GLM / DeepSeek / Moonshot）
- 备用模型：下拉框（主模型挂了自动切）
- Temperature：滑块（0-1，默认 0.2）
- Max Tokens：输入框（默认 1024）
- 提示词缓存：开关（默认开）
- 切换提示：改完点 [保存] → 立即生效

#### 5.4.2 提示词配置 `/admin/model/prompt`（C3）

- 左侧：版本列表（v1 / v2 / v3...）+ 状态（生产中 / 草稿）
- 右侧：编辑器（`<TextArea>` + 行号）+ 实时预览
- 顶部：「保存草稿」「发布版本」「回滚到 v1」
- 变更要跑评测 → 跳转评测页

### 5.5 工具管理 `/admin/tools`（C2 / Phase 2）

- 工具列表（AntD Table）：name / type（builtin / mcp）/ 状态 / 描述
- 「注册 MCP 服务」按钮：弹窗填表单（name / baseURL / tools list）
- 工具详情抽屉：调用历史 + 错误率 + 平均耗时

### 5.6 评测

#### 5.6.1 评测集 `/admin/evaluation/datasets`（P6）

- 列表：name / version / 条数 / 创建时间
- 「上传评测集」按钮：拖 JSONL → 解析 → 入库
- 单击：显示前 10 条预览

#### 5.6.2 评测结果 `/admin/evaluation/runs`（P7）

- 趋势图（ECharts 折线）：4 维分数（accuracy / completeness / style / safety）
- 列表：每次跑的结果（时间 / prompt 版本 / 模型 / 4 维分数 / 总成本）
- 单击：详细打分（每条 case 的 + 大模型裁判理由）

### 5.9 租户设置 `/admin/settings`（E2）

- Tab 切换：基础配置 / 限额 / 安全 / API 密钥

#### 5.9.1 基础配置

- 租户名（只读）
- 租户号（只读）
- 提示词版本（下拉）
- 默认模型（下拉）
- 嵌入模型（下拉）

#### 5.9.2 限额

- 月度 token 配额（输入数字）
- 告警阈值（百分比）
- 单租户 QPS 限制

#### 5.9.3 安全

- 注入检测开关
- 输入审核开关
- 输出审核开关
- 脱敏开关

#### 5.9.4 API 密钥

- 列表：name / key（部分遮蔽）/ 创建时间 / 最后使用
- 「生成新密钥」按钮

### 5.10 审计日志 `/admin/audit`

- 列表：时间 / 用户 / 操作 / 资源 / IP
- 筛选：用户 / 时间 / 操作类型
